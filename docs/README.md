# Documentation Structure

- **architecture/**: System architecture, diagrams, and high-level overviews.
- **docker/**: Docker-related documentation.
- **features/**: Feature-specific documentation, grouped by feature area (JetDrive, Virtual Tuning, etc.).
- **guides/**: User guides, quick start guides, and how-to articles.
- **history/**: Historical documentation and logs.
- **plans/**: Roadmaps, migration plans, and future work.
- **reports/**: Technical reports, summaries, and audit results.
- **specs/**: Technical specifications and schemas.
